# 首版架构

## 技术栈

- Go 1.25 或更高版本
- Bubble Tea v2、Bubbles v2 和 Lip Gloss v2 构建 TUI
- 标准库 `net/http` 实现本地代理和流式转发
- YAML 保存人类可读配置与独立凭证文件
- JSON 保存小型运行状态快照
- `log/slog` 输出结构化 JSONL，使用 lumberjack 轮转

第一版不引入数据库、Web UI、后台守护进程或完整 API 网关框架。

## 组件边界

- **domain**：服务配置、路由池、上游凭证、状态转换和选择策略；不依赖 TUI 或 HTTP。
- **router**：本地端点、认证注入、请求重放、响应检查、透明切换和流式转发。
- **probe**：验证请求生成、手动及周期验证调度。
- **config**：配置校验、默认值、YAML 加载和原子保存。
- **store**：凭证文件权限检查、运行状态恢复和原子快照。
- **logging**：请求关联、脱敏、结构化输出、轮转和 TUI 日志订阅。
- **tui**：首次向导、仪表盘、配置表单、凭证操作、规则测试和日志视图。

核心领域、路由和分类逻辑不得依赖 TUI，以便使用确定性单元测试和 `httptest` 集成测试覆盖。
